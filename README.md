## 📌 Sobre o Projeto

Este repositório contém as soluções desenvolvidas para a atividade prática individual da unidade curricular de **Programação JavaScript** do SENAI. O objetivo principal da atividade é aplicar os conceitos fundamentais de lógica de programação utilizando JavaScript, como manipulação de variáveis, operadores aritméticos, entrada e saída de dados, e versionamento de código com **Git e GitHub**.

---

## 💻 Exercícios Desenvolvidos

### 1. 🎓 Exercício 1: Cálculo da Média de um Aluno
- **Descrição:** Calcula a média aritmética final de um aluno com base em quatro notas obtidas ao longo do período letivo.
- **Conceitos utilizados:** Declaração e atribuição de variáveis, operadores aritméticos e exibição de resultados no console com `console.log()`.

### 2. 📊 Exercício 2: Cálculo da Média de Vendas
- **Descrição:** Calcula a média semanal de vendas realizadas por um vendedor ao longo de quatro semanas.
- **Conceitos utilizados:** Entrada de dados dinâmicos com `prompt()`, conversão de tipos de dados (`parseFloat()`), operadores aritméticos e formatação monetária de números com `toFixed(2)`.

### 3. ⚡ Exercício 3: Média de Consumo de Energia
- **Descrição:** Acompanha o consumo mensal de energia elétrica de uma residência durante quatro meses e verifica se a média obtida está dentro da meta estipulada de até 150 kWh.
- **Conceitos utilizados:** Entrada e conversão de dados, cálculos aritméticos, validação lógica condicional e apresentação clara de resultados.

## 📂 Como Executar os Programas

### Pré-requisitos
Ter o [Node.js](https://nodejs.org/) instalado no computador ou utilizar um navegador web moderno (Google Chrome, Microsoft Edge, etc.).

### Passo a passo
1. Clone este repositório para a sua máquina local:
   ```bash
    git clone [https://github.com/SEU-USUARIO/trabalho-javascript.git](https://github.com/SEU-USUARIO/trabalho-javascript.git)

2. Navega até à pasta do projeto:
  ```bash
    cd trabalho-javascript

3. Para executar os ficheiros diretamente no terminal através do Node.js:
  node exercicio1.js
  node exercicio2.js
  node exercicio3.js
---
(Nota: Para os exercícios que utilizam a função prompt(), também podes testar colando o código diretamente no Console do Desenvolvedor do navegador pressionando F12).
